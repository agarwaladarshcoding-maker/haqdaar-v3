# work-adarsh/ — only your hands

One file per day: `work-adarsh/<YYYY-MM-DD>.md`.

This folder holds **only what a tool cannot do**: open an account, hold a phone,
pay for something, make a call on a judgement, say yes to a merge.

If a job can be typed into Antigravity, it does **not** belong here. It belongs in
[`work-with-tools/`](../work-with-tools/).

| Folder | Who acts | What is in it |
|---|---|---|
| `work-adarsh/` | you | accounts, keys, the phone call, decisions, merges |
| `work-with-tools/` | Antigravity + me | the prompt to paste, the check to run, the review block |

**Every day has two files.** Open both. Start with `work-with-tools/` — paste the first
prompt so a tool is busy — then work down `work-adarsh/` while it runs.

**Rule:** anything you do off-script goes as one dated line into `WORK.md` §8.
If it is not written there, I do not know it happened.
